# Data sources

All files in this folder are either public data (downloaded once, then cached) or
generated by the project. Delete a file to force a fresh download.

| File | What | Source | Licence / notes |
|---|---|---|---|
| `influenza_england_1978_school.RData` | Raw download of the 1978 boarding-school influenza outbreak | RECON `outbreaks` R package, https://github.com/reconhub/outbreaks (original: *BMJ* 1978, 1(6112):587, "Influenza in a boarding school") | Public dataset, used widely in teaching |
| `boarding_school_flu_1978.csv` | The same data converted to CSV (`date, in_bed, convalescent`) | derived from the file above | |
| `jhu_confirmed_global.csv`, `jhu_deaths_global.csv` | COVID-19 cumulative confirmed cases and deaths by country, 2020-01-22 to 2023-03-09 | JHU CSSE COVID-19 Data Repository, https://github.com/CSSEGISandData/COVID-19 | CC BY 4.0 |
| `synthetic_outbreak.csv`, `synthetic_outbreak_truth.json` | **SYNTHETIC** SIR outbreak with known parameters and Poisson observation noise | generated by `src/data.py` (seed 42) | Not real data. Used to check that the fitting code recovers known parameters |
